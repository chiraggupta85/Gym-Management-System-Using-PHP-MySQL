# 🏋️ OldSkoll Gym Management System

A full-stack Gym Management System built using PHP and MySQL.

---

## 🚀 Features

- User Registration & Login
- Admin Dashboard
- User Dashboard
- Trainer Role System
- CRUD Operations
- Search Functionality
- Dynamic Dashboard Cards
- Session Authentication
- Modern UI Design

---

## 🛠 Tech Stack

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

---


## ⚡ How to Run

1. Install XAMPP
2. Start Apache & MySQL
3. Import database in phpMyAdmin
4. Move project folder to htdocs
5. Run: 

http://localhost/gym.php
